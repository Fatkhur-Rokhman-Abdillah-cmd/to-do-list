Tentang Aplikasi

✓ TodoApp

Aplikasi todo-list sederhana yang dibangun dengan HTML, CSS, dan JavaScript vanilla. Data disimpan secara lokal di browser menggunakan localStorage.

Fitur

  • ✅ Tambah, edit, hapus task
  • ✅ Tandai selesai / aktif
  • ✅ Prioritas (Low / Medium / High)
  • ✅ Filter by status, prioritas, dan pencarian
  • ✅ Deadline dengan indikator overdue
  • ✅ Statistik & progress bar

Struktur Kode

Kode JavaScript dipecah menjadi modul-modul kecil: Config, Storage, TaskService, Renderer, dan Page Controller.
